Evaluating multilingual LLM outputs

Why English-only evaluation misleads, and how to design rubrics and rater pools that work across languages and cultures.

Do not translate your English eval set and stop

Translated prompts carry English assumptions about politeness, humor and context. Native writers should adapt or author prompts per locale so you test the situations real users create.

One rubric, local notes

Keep a shared rubric so results compare across languages, then add per-locale notes: register, honorifics, script conventions, culturally sensitive topics. Raters need both.

Rate what users notice

Accuracy and helpfulness matter, but so do fluency, tone and cultural fit. A correct answer in the wrong register still feels broken to a native speaker.

Calibrate every pool

Run calibration rounds per language against reference items. Agreement can differ a lot between locales; a weak pool produces misleading results no matter how good the rubric is.

Report per locale

Averages across languages hide failures in smaller markets. Report each locale separately, with examples of typical issues, so teams can fix what matters where it matters.
