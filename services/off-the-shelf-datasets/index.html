FAQ

Can we see a sample before licensing?

Yes. Every catalog set has a sample and a data card you can review before any agreement.

What if a dataset is close but not exact?

We can extend it with custom collection or annotation that follows the same schema and guidelines.

How is consent documented?

Each dataset's data card explains how contributors were recruited, what they agreed to and how the data may be used.
